repetitorbot — Telegram-бот для учёта учеников, занятий и оплат

Telegram-бот, который заменяет репетитору таблицы и блокноты: ученики, расписание занятий, долги и оплаты — всё в одном чате. Версия 2 — самостоятельный многопользовательский сервис с подпиской, бесплатным триалом и жёсткой изоляцией данных между пользователями.

Частный репетитор ведёт десятки учеников и считает деньги вручную: кто сколько должен, когда следующее занятие, кто предупредил об отмене. Готовые CRM избыточны и стоят денег, а таблицы быстро расходятся с реальностью. repetitorbot решает это там, где репетитор и так проводит день — в Telegram.

Что умеет бот

Список учеников: имя, предмет, цена занятия, контакт, заметка, архив. Тёзки различаются в кнопках по заметке, а без неё — по номеру (Иван (Петров) / Иван (#7)). Планирование занятия через календарь: месяц → день → часы → минуты → длительность. Прошедшие дни в календаре видны, но недоступны, сегодняшний выделен. Закрытие занятия итогом: проведено / прогул / отменено / перенесено. Перенос создаёт новое занятие, а не переписывает историю. Автоматический расчёт долга и аванса: долг = проведённые занятия − оплаты. Никакой ручной арифметики. Оплаты с историей и приём платежей через Telegram Stars, планы подписки, продление, возвраты. Экспорт данных в JSON и CSV (ZIP) — данные не заперты внутри бота. Часовые пояса: 11 зон, все даты и суммы показываются в поясе пользователя. Инженерные решения, которыми проект интересен

Изоляция данных как инвариант. В v2 каждый пользователь видит только своё: все запросы идут с user_id, внешние ключи составные (user_id, id), а на это есть отдельный набор тестов изоляции. Защита от злоупотребления триалом. 7 дней бесплатно, но повторный триал не выдаётся: в trial_ledger хранится хэш идентификатора с солью, а не сам идентификатор. Плюс админ-команда /trial <id> <дней> для продления тестировщикам. Юридический слой. Экран согласия с публичной офертой и политикой конфиденциальности (ссылки на документы), фиксация даты и версии согласия, удаление данных по /delete_me. Тексты вынесены в конфиг, чтобы менять их без правки кода. Админка в Telegram: статистика, продление доступа, отзыв, возвраты, чеки, журнал действий с аудитом. Тесты вместо надежды. 249 автотестов v2 покрывают сценарии, а не только функции: фейковый Telegram-транспорт, реальный PostgreSQL с отдельной схемой на каждый тест, регресс-тесты на баги, найденные на живом сервере — «message is not modified» при повторном нажатии кнопки, сдвиг дней в календаре, parse_mode=HTML. Деплой как часть продукта. systemd-юнит с RestartPreventExitStatus=2 (второй экземпляр бота на том же токене не должен перезапускаться бесконечно), режим --check для проверки конфига и базы без запуска polling, документированный перенос на VPS и бэкапы. Безопасность по умолчанию: секреты только в .env, маскирование в логах и трейсбеках, repr конфига не печатает токен и пароль. Результат. Рабочий бот, которым можно пользоваться каждый день, и вторая версия — многопользовательский сервис с подпиской, триалом, оплатой и админкой. Проект довёл от спецификации до сервера: код, тесты, миграции, юридические тексты, документация по установке и инструкция для новичка на PowerShell.
